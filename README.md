# WebDev_Project_HCD

### Website Development 1 – Team Project

This repository contains **Team HCD’s web development project** for the Website Development 1 module. The goal is to design and build a responsive website for our fictional client, **John O’Reilly**, to showcase his classic and luxury car collection and allow visitors to explore and purchase vehicles.

---

## 🚗 Project Overview
Our website focuses on both **aesthetic design** and **usability**, aiming to deliver an engaging experience for all users, including those with visual impairments. It is currently hosted via **GitHub Pages**.

---

## 🌟 Key Features
- **Featured Car of the Week:** Interactive sliding image cascade highlighting selected models.  
- **Accessibility Options:** High-contrast mode and layout considerations for visually impaired users.  
- **Car Model Information:** Detailed sections showcasing specifications and descriptions for each vehicle.  
- **Search Functionality:** Easily locate cars and content across the site.  
- **About & Contact Pages:** Information about the client and methods to get in touch.
